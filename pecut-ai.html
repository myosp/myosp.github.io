PROMPT DEWA

Pecut AI

Siapkan asisten dari folder kosong atau folder yang sudah terisi. Tambahkan pengetahuannya seiring pekerjaan berjalan.

✦ Memerlukan akses agent berbayar

Konteks tersimpan

Lanjutkan pekerjaan tanpa mengulang cerita dari awal.

File langsung rapi

Simpan, namai, dan tempatkan file baru sesuai isinya.

Bantu buat laporan

Susun draf laporan, notulen, atau rekap dari bahan di repo.

Status sesi

Lihat progres, hambatan, dan langkah berikutnya.

Serah terima

Catat hasil kerja agar sesi berikutnya tinggal lanjut.

Audit & sinkron

Periksa duplikat, lokasi file, dan catatan yang usang.

Mulai dalam 3 langkah

Cukup sekali saat setup
  1. 01

    Buka folder kerja

    Hubungkan repo atau folder Anda ke tool AI.

  2. 02

    Salin & kirim prompt

    Tempel prompt lengkap ke percakapan agent.

  3. 03

    Analisis, lalu setujui

    AI membaca bahan yang tersedia atau bertanya jika folder kosong. Pilih peran asisten dan setujui rencananya.

Sesudah setup, tinggal pakai

/status
Mulai sesi, cek progres.
/lapor
Susun draf laporan.
/update
Simpan pengetahuan atau koreksi.
/sync
Audit dan rapikan repo.
/handoff
Simpan konteks sebelum selesai.
Cara menambah pengetahuan

Ketik /update disertai arahan, koreksi, atau dokumen baru. Contoh: /update Mulai semester ini, pakai template laporan terbaru di folder referensi.

Asisten mencatat sumber dan tanggalnya agar bisa dipakai di sesi berikutnya.

Bagaimana kalau menambahkan file manual?

File yang diberikan ke agent diproses lewat Auto-Ingest: disimpan, dianalisis, diberi nama, lalu ditempatkan di folder yang sesuai.

File yang dimasukkan lewat File Explorer diperiksa pada awal sesi berikutnya. Jika sesi sedang terbuka, beri tahu agent path file-nya. Gunakan /sync untuk audit menyeluruh; perubahan dilakukan setelah Anda menyetujui usulannya.

Agent bekerja saat sesi aktif, bukan memantau folder ketika sesi ditutup.

Tool yang didukung & contoh perintah

Prompt disiapkan untuk Claude Code dan Codex. Untuk Antigravity, sesuaikan file aturan dan cara menjalankan agent.

Jika slash command tidak tersedia, tulis: Jalankan prosedur /status di AGENTS.md (Codex), atau rujuk CLAUDE.md (Claude Code).

Contoh laporan: Buat laporan pengabdian semester ini berdasarkan dokumen di repo. Sebutkan periode dan template, lalu periksa hasilnya sebelum dipakai.
