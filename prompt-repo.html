PROMPT DEWA · STARTER KIT

Asisten Repo
Starter Kit

Ubah repo atau folder kerja menjadi asisten yang menyimpan konteks lewat file di repo. Salin prompt ini saat pertama kali menyiapkan asisten Anda.

Syarat penggunaan: fitur berbayar.

Gunakan akun atau akses berbayar yang mendukung agent untuk membaca dan mengubah file di repo. Menyalin prompt di myOSP tidak memerlukan login.

Asisten ini bisa membantu apa?

Setelah setup disetujui, agent bekerja mengikuti peran yang Anda tentukan, misalnya asisten penelitian, pengabdian, SKP, atau sekretaris unit.

Melanjutkan konteks antar sesi
Menyimpan progres, keputusan, dan preferensi dalam file repo. Saat sesi baru dimulai, agent membaca catatan tersebut untuk melanjutkan pekerjaan.
Menyimpan dan merapikan file masuk
Saat Anda memberi lampiran atau path file yang bisa diakses agent, Auto-Ingest menyimpan salinannya di repo, membaca isi, menentukan folder dan nama standar, lalu mencatatnya di log. Jika tujuan file belum jelas, agent bertanya.
Menata file kerja lama
Agent mengusulkan struktur folder dan rencana penamaan. Pemindahan file lama dilakukan setelah Anda menyetujui rencana, dengan riwayat perubahan tetap dicatat.
Membantu menyusun berbagai laporan
Gunakan data yang tersedia untuk membuat draf laporan penelitian, pengabdian, SKP, akreditasi, notulen, atau rekap sesuai peran asisten. Jelaskan tujuan, periode, pembaca, dan template; periksa hasil sebelum dipakai resmi.
Mengaudit dan menyelaraskan repo
Prosedur /sync mencari duplikat, file salah tempat, nama yang tidak konsisten, antrean yang tertinggal, dan informasi usang. Agent menampilkan usulan sebelum melakukan perubahan.
Menyiapkan status dan serah terima
/status membantu memulai sesi dengan progres dan langkah berikutnya. /handoff menutup sesi dengan catatan pekerjaan, keputusan, dan hal yang perlu dilanjutkan.

Setup pertama kali

  1. Hubungkan atau buka folder kerja Anda di Claude Code, Codex, atau tool AI yang digunakan, agar agent bisa mengakses isinya.
  2. Tekan Salin prompt, lalu tempel dan kirim seluruh isinya ke percakapan agent di folder tersebut.
  3. AI mulai dengan menganalisis struktur folder dan isi file kerja yang dapat diakses, tanpa mengubah apa pun. File sensitif dan file yang diabaikan sesuai aturan prompt tidak dibaca.
  4. Dari hasil analisis, AI mengusulkan peran asisten dan rencana penataan. Jawab pertanyaannya, tentukan peran yang sesuai, lalu setujui rencana sebelum setup dijalankan.

Dokumen ini disiapkan untuk Claude Code dan Codex. Untuk Antigravity, sesuaikan petunjuk file aturan dan cara menjalankan agent dengan fitur yang tersedia di tool tersebut.

Rutinitas setelah setup

Starter kit cukup dijalankan sekali saat penyiapan. Pada sesi berikutnya, buka repo yang sama dan gunakan prosedur berikut.

Kapan?Yang Anda ketik atau lakukanHasil yang diminta dari agent
Mulai sesi baru/statusMembaca status, catatan serah terima, dan perubahan terakhir; merangkum progres, hambatan, serta tiga langkah prioritas.
Ada file baruLampirkan file atau berikan path yang bisa diakses agent.Auto-Ingest menyimpan, menganalisis, menamai, dan menempatkan file serta memperbarui log dan status. Nama yang bentrok diberi versi; file lama tidak ditimpa.
Menyusun laporan/lapor, lalu jelaskan kebutuhan. Contoh: “Buat draf laporan pengabdian semester ini berdasarkan dokumen di repo dan template yang saya berikan.”Mengonfirmasi tujuan, periode, dan pembaca; mengumpulkan bahan; menyimpan draf di folder laporan sesuai gaya yang disepakati.
Audit berkala atau setelah banyak perubahan/syncMemeriksa kerapian file dan kesesuaian catatan kerja. Anda meninjau usulan; perubahan dilakukan setelah disetujui dan hal usang diarsipkan.
Sebelum menutup sesi/handoffMencatat yang selesai, belum selesai, keputusan, dan langkah berikutnya; memperbarui status, memori, dan log agar sesi berikutnya bisa dilanjutkan.

Jika slash command tidak tersedia di tool Anda, tulis instruksinya sebagai kalimat biasa, misalnya Jalankan prosedur /status di AGENTS.md untuk Codex, atau rujuk CLAUDE.md untuk Claude Code.

Kalau file dimasukkan manual?

Ada mekanismenya. Aturan starter kit meminta agent mengecek file baru yang belum tercatat di INGEST_LOG.md pada awal setiap sesi.

  1. Letakkan file di folder repo melalui File Explorer atau pengelola file Anda.
  2. Saat membuka sesi baru di repo yang sama, agent diminta memeriksa file yang belum tercatat dan memprosesnya lewat Auto-Ingest. Jika sesi sudah terbuka, beri tahu agent lokasi file yang baru ditambahkan.
  3. Untuk pemeriksaan menyeluruh, jalankan /sync. Tinjau usulan penamaan, lokasi, duplikat, dan catatan yang perlu diperbarui sebelum menyetujui perubahan.

Sinkronisasi di sini berarti menyelaraskan file, struktur folder, dan catatan kerja di repo. Agent juga diminta mengingatkan sync jika sudah lebih dari 30 hari atau lebih dari 20 file baru sejak sync terakhir; pelaksanaannya tetap menunggu perintah Anda.

Berjalan saat sesi agent aktif. Agent tidak memantau folder ketika sesi ditutup. Pemrosesan file memerlukan akses agent ke repo dan file tersebut. Satu repo menyimpan konteks satu asisten; catatan kerja pribadi tetap dijaga di repo Anda.
