Asisten Repo
Starter Kit

Ubah repo atau folder kerja menjadi asisten yang menyimpan konteks lewat file di repo. Salin prompt ini saat pertama kali menyiapkan asisten Anda.

Syarat penggunaan: fitur berbayar.

Gunakan akun atau akses berbayar yang mendukung agent untuk membaca dan mengubah file di repo. Menyalin prompt di myOSP tidak memerlukan login.

Cara pakai

  1. Backup folder kerja Anda, lalu buka repo atau folder tersebut di tool AI yang digunakan.
  2. Tekan Salin prompt, lalu tempel seluruh isinya ke percakapan agent saat setup pertama.
  3. Kirim prompt, jawab pertanyaan tentang peran asisten, lalu periksa dan setujui rencana sebelum agent mengubah file lama.

Dokumen ini disiapkan untuk Claude Code dan Codex. Untuk Antigravity, sesuaikan petunjuk file aturan dan cara menjalankan agent dengan fitur yang tersedia di tool tersebut.

Prompt lengkap

Markdown asli, termasuk heading, daftar, tabel, dan blok kode.
